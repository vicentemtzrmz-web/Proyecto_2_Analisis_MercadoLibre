# Proyecto_2_Analisis_MercadoLibre
Se realizó un análisis de embudo y retencion para Mercado Libre. Esto para detectar en que etapa del viaje del usuario se perdían clientes. Así como también se obtuvo los porcentajes de conversión por etapa. Esto ayuda al negocio a tomar decisiones informadas para implementar mejoras en  ecommerce.
